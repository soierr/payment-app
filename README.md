### Payment Application

A playground to solidify common approaches in Java Spring app development and check some interesting ideas

Not a business application, based on real enterprise experience though

- pipeline feature setup: docker image publish to Docker Hub for integration tests

- release job setup with maven-release-plugin
- java-client generation setup
- open api, i.e. swagger, doc creation
- secrets storage revisiting even for local env
